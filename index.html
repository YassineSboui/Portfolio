About me

I'm a Tunisia-based full-stack software developer and software-engineering student at Esprit, currently on a work-study program (alternance) with NeoLedge. I enjoy turning complex business problems into clean, maintainable software — my day-to-day spans the whole stack, from component architectures on the front end to modular, multi-tenant services on the back end.

At NeoLedge I work on NeoForm V2, a dynamic form & table platform that lets businesses design workflows visually, automate logic with Blockly, and integrate with external APIs, databases, and document systems. Outside of work I explore AI/NLP, data engineering, and the occasional low-level simulation in C.

I care about performance, accessibility, and code that the next developer (often future me) can actually read.

Featured projects

Flagship · NeoLedge

NeoForm V2

A multi-tenant platform for designing dynamic business forms, tables, and workflows — then executing them at scale. Users build schemas visually, wire up logic with Blockly, and connect to external APIs, databases, SMTP, Automate/ECS, and the Elise document engine. Generates Word/PDF documents on submission and ships with full observability (Serilog · Loki · Grafana).

  • Definition-driven engine — forms, tables, apps & configs as versioned JSON
  • Visual form/table designers with drag-and-drop & live runtime
  • Modular ASP.NET Core API with tenant resolution & secret protection
  • Blockly automation injecting field / API / Elise / table utilities
